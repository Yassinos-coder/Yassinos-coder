# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-10-27

### Added

- Redesigned profile README with a gradient banner, a TypeScript profile block, featured work, open source and a refreshed tech stack
- Discord contact, the updated portfolio address and the current email
- GitHub stats cards, top languages and a contributions summary card

### Changed

- Experience and project details updated to match the current portfolio
- Open source section now lists nestjs-shield and the NestJS API Railway Template, with a Deploy on Railway button

### Removed

- X and Twitch links, the old email and portfolio address, and widgets that no longer load reliably (typing animation, streak stats, profile views, trophies and the activity graph)
